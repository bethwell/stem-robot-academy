1. The micro:bit screen

The front of a micro:bit has 25 tiny red lights called LEDs, arranged in 5 rows of 5. Each LED can be ON (lit) or OFF (dark). Every picture you make is just a pattern of ONs and OFFs — just like the pixels on a phone screen!


25 LEDs make a heart

2. Drawing a picture

  1. Open the 💡 LED Designer tab.
  2. Tap an LED to turn it ON. Tap it again to turn it OFF.
  3. To draw faster, press and drag your finger (or mouse) across the LEDs.
💡 Tip: if you start dragging on an OFF light, everything you drag over turns ON. Start on an ON light and you rub them out, like an eraser.

3. Handy tools

ButtonWhat it does
🧹 ClearTurns every LED off so you can start again.
🔄 Flip on/offSwaps every light: ON becomes OFF and OFF becomes ON.
⬅️ ➡️ ⬆️ ⬇️Slides your whole picture one step. Lights that slide off the edge disappear.
📍 Show x,yShows the number of every row and column (see Coordinate Quest).
❤️ Heart and other stampsPuts a ready-made picture on the screen. Great for a quick start — then change it to make it your own!

4. Making an animation

An animation is lots of still pictures (called frames) shown quickly one after another — just like a cartoon flip-book.

  1. Draw your first picture.
  2. Tap ⧉ Copy frame to make a copy of it.
  3. Change the copy a little (the ➡️ button is perfect for moving things).
  4. Repeat until you have all your frames. You can have up to 12.
  5. Tap ▶ Play to watch it. Choose Fast, Medium or Slow.
  • Tap a small frame picture to go back and edit it.
  • ➕ New frame adds an empty frame. 🗑 Delete frame removes the one you're on.
💡 Tip: small changes between frames make smooth animations. Big changes make it look jumpy.

5. Reading your code

While you draw, the LED Designer writes the code for you. Choose how you want to see it:

  • Blocks — looks just like MakeCode. Each show leds block is one frame.
  • JavaScript and Python — the same program written as text, for older MiniMakers.

What the blocks mean

  • on start — runs once when the micro:bit turns on. You get this with one frame.
  • forever — repeats again and again. You get this with two or more frames, so your animation keeps playing. This is called a loop.
  • pause (ms) — waits before the next frame. 1000 ms = 1 second.

In the code, # means an LED is ON and . means it is OFF:

basic.showLeds(`
    . # . # .
    # # # # #
    # # # # #
    . # # # .
    . . # . .
    `)

6. Putting it on a real micro:bit

  1. In the LED Designer, tap 📋 Copy code. (It doesn't matter which view you're on — Blocks copies the JavaScript.)
  2. Tap 🚀 Open MakeCode and click New Project. Give it a name.
  3. At the top of MakeCode, click JavaScript.
  4. Click inside the code, select everything (Ctrl + A) and paste (Ctrl + V).
  5. Click Blocks at the top — your blocks appear!
  6. Plug the micro:bit into the computer with a USB cable.
  7. Click Download. If MakeCode asks to pair, follow its steps; otherwise drag the downloaded .hex file onto the MICROBIT drive.
  8. Watch your picture light up on the micro:bit! 🎉
💡 Want Python instead? In MakeCode click Python at the top, then paste the code from the LED Designer's Python view.
⚠️ If your animation looks a bit slower on the real micro:bit, that's normal: each show leds block waits about 0.4 seconds on its own, plus your pause. The Play button already copies this timing.

7. Coordinate Quest

Every LED has an address made of two numbers: x and y.

  • x counts across → from left to right.
  • y counts down ↓ from top to bottom.
  • Both start at 0, not 1! So they go 0, 1, 2, 3, 4.

The lit LED is at x = 3, y = 1: go 3 across, then 1 down.

Tap 🎯 Coordinate Quest, then tap the LED the game asks for. Find all 5 to win ⭐⭐. If you pick the wrong one, the game tells you its address so you can try again.

💡 In MakeCode, the plot x y block (in the Led section) uses these exact numbers to turn on one LED at a time.

8. Challenges to try

⭐ Easy: Draw the first letter of your name.
⭐ Easy: Make a heart that blinks (2 frames: heart, then empty).
⭐⭐ Medium: Make an arrow that moves across the screen using ➡️ and Copy frame.
⭐⭐ Medium: Make a smiley that turns into a sad face and back.
⭐⭐⭐ Hard: Make a rain animation: drops falling from top to bottom.
⭐⭐⭐ Hard: Put your animation on your robot, then change the pause in the code to make it faster.

9. Something not working?

ProblemTry this
Copy code doesn't paste anythingSwitch to the JavaScript view, press and hold (or drag) to select the code, and copy it yourself.
MakeCode shows red errors after pastingMake sure you deleted the old code first (Ctrl + A, then paste), and that you pasted into the JavaScript view, not Python.
The micro:bit doesn't show up on the computerSome USB cables only charge. Try a different cable. Check the micro:bit's yellow light comes on.
Nothing happens on the micro:bitWait for the download to finish (the yellow light flashes, then stops). Press the reset button on the back.
My drawing disappearedYour work is saved on this device and browser only. On a different phone or computer you'll start fresh.
No sound when tapping LEDsSound may be turned off in another game (🔇). Turn it on there, or check your device volume.

10. For teachers & parents

What learners practise

  • Pixels and on/off (binary) thinking on a 5 × 5 grid.
  • x, y coordinates starting from 0 — the basis of MakeCode's plot x y and of moving robots on a grid.
  • Sequences (frames in order) and loops (forever vs on start).
  • Design → test → improve, and moving code from the screen onto real hardware.

Suggested targets by age

AgeLearner can…
5–7Draw a picture, use stamps, make a 2-frame blink, and show it on a micro:bit with help.
8–10Finish the Coordinate Quest, make a 4–6 frame animation, copy it into MakeCode on their own, and explain on start vs forever.
11–15Plan an animation before drawing, read and edit the JavaScript or Python (e.g. change the pause), and explain what a loop does.

A 20-minute session

  1. 5 min — Show the micro:bit's 25 LEDs. Learners draw any picture.
  2. 5 min — Coordinate Quest (everyone tries for 5/5).
  3. 7 min — Make a 2–3 frame animation and press Play.
  4. 3 min — Download one or two learners' animations onto a micro:bit robot for everyone to see.

Quick checks

  • "Light up x = 4, y = 0." — Most learners should get it first time after the quest.
  • "Why does your animation keep repeating?" — "Because it's in a forever loop."
  • Older learners: change one number in the code to make it faster and explain what changed.
